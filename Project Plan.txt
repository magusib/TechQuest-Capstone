Forgot Password Requirements
The Forgot Password popup must contain:


* Email Input Field
* New Password Input Field
* Confirm Password Input Field
* Save Button


Save Button Behavior
When the Save button is clicked:
1. Validate the entered email.
2. Validate that both passwords match.
3. Send a 6-digit OTP to the user's email.
4. Display the OTP Verification popup.
Email OTP Verification Requirements
The OTP Verification popup must contain:
* 6-digit OTP Input Field (Numbers Only)
* Confirm Button
* Resend OTP Button
Confirm Button Behavior
When the OTP is successfully verified:
1. Close the OTP popup.
2. Return to the Registration Form (or Forgot Password form if resetting a password).
3. Display a ✔ Verified indicator beside the Email field.
4. Allow the registration or password reset process to continue.
Resend Button Behavior
When clicked:
* Generate a new 6-digit OTP.
* Send the new OTP to the user's registered email.
* Invalidate the previous OTP.
